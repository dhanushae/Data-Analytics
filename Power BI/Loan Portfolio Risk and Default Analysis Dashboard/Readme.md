# 📊 Loan Portfolio Risk and Default Analysis Dashboard (Python + Power BI)

## 📌 Project Overview
This project analyzes **loan portfolio performance and default risk** using **Python for data preprocessing** and **Power BI for interactive dashboard visualization**.

The analysis provides a comprehensive understanding of **loan distribution, borrower demographics, financial risk indicators, and default patterns**. The goal is to help financial institutions identify risk-prone borrower segments and support **data-driven lending decisions**.

The Power BI dashboard contains **four interactive analytical pages** that provide insights into different aspects of loan portfolio performance.

This project demonstrates practical applications of **data preprocessing, financial risk analytics, and business intelligence reporting**.

---

# 🎯 Key Objectives

- Clean and preprocess raw loan data using **Python**
- Analyze **loan portfolio distribution and borrower characteristics**
- Identify patterns in **loan defaults and financial risk indicators**
- Evaluate **credit score trends and borrower demographics**
- Build a **multi-page interactive Power BI dashboard**
- Generate **actionable insights for risk management and lending decisions**

---

# 🗂 Dataset Description

**Dataset:** Loan Portfolio Dataset

### Key Columns

| Column Name | Description |
|--------------|-------------|
| loan_id | Unique identifier for each loan |
| borrower_age | Age of borrower |
| employment_status | Employment type of borrower |
| loan_purpose | Purpose of the loan |
| loan_amount | Total loan amount |
| credit_score | Borrower credit score |
| income | Borrower's annual income |
| debt_to_income_ratio | Financial risk indicator |
| loan_term | Duration of loan |
| interest_rate | Loan interest rate |
| default_status | Indicates whether the loan defaulted |

# 📊 Power BI Dashboard

The Power BI report contains **four interactive pages**, each analyzing loan portfolio performance from different perspectives.

---

## 1️⃣ Loan Portfolio – Executive Summary

### Purpose
Provides a high-level overview of the loan portfolio and key performance indicators.

### Key Metrics

- Total Loans
- Total Loan Amount
- Default Rate (%)
- Average Credit Score

### Visualizations

- Loan Portfolio Distribution by Default Status
- Loan Distribution Across Borrower Age Groups

### Insight
Provides a quick snapshot of portfolio health and highlights the proportion of loans at risk.

---

## 2️⃣ Borrower Demographics Analysis

### Purpose
Analyzes borrower characteristics to understand how demographics influence loan distribution.

### Visualizations

- Borrower Distribution by Marital Status
- Loans by Education Level and Default Status
- Loans by Employment Type and Default Status

### Insight
Identifies borrower segments contributing most to loan portfolio exposure.

---

## 3️⃣ Financial Risk and Default Analysis

### Purpose
Examines financial indicators that influence loan defaults.

### Visualizations

- Credit Score vs Debt-to-Income Ratio
- Loan Purpose vs Employment Type by Age Group
- Default Rate Percentage by Loan Purpose

### Insight
Shows how financial metrics relate to default probability and risk exposure.

---

## 4️⃣ Loan Portfolio Performance

### Purpose
Evaluates overall portfolio performance across loan categories.

### Visualizations

- Average Interest Rate by Loan Term
- Loans by Mortgage Status
- Default Rate Percentage by Months Employed

### Insight
Highlights loan segments that generate higher risk and those that perform better.

---

# 🔍 Key Insights

- Majority of loans belong to **middle-age borrower groups**, indicating strong borrowing activity.
- Borrowers with **higher credit scores show significantly lower default rates**.
- Certain **loan purposes contribute more to portfolio risk**.
- **High debt-to-income ratios** are strongly associated with loan defaults.
- Monitoring borrower financial indicators improves **risk prediction and lending strategies**.
